## PDF Anchor privacy policy

**Effective date:** September 25, 2026

This policy describes the PDF Anchor Android app, a PDF reader created and owned by Ethan Stidley.

**Developer:** Ethan Stidley

**Contact:** [estidley@gmail.com](mailto:estidley@gmail.com)

### The app

PDF Anchor is a local-only PDF reader. There is no PDF Anchor account. There is no PDF Anchor backend or server. Documents are not synced to the cloud.

### Data on the device

When you open a PDF, PDF Anchor copies it into app-private storage. It also stores, on the device:

- The file name used to display the document
- How many pages it has, and the last page you read
- Highlights and notes you add

This data stays on the device. PDF Anchor does not upload it.

### Network

The app does not request Internet access. It does not include an analytics SDK, an advertising SDK, or a crash-reporting SDK. It does not use Google Play Billing.

### Permissions

PDF Anchor does not request any Android permissions. You pick files through the system document picker, or by opening a PDF from another app.

### Backup

Android backup and device transfer are off (`allowBackup=false`). Copies, highlights, and notes are not included in Google backup or device transfer.

### Deleting data

Delete a document inside the app, or uninstall PDF Anchor. Uninstalling removes the app's private data from the device.

PDF Anchor has no accounts, so there is no account-deletion page.

### Changes

This policy may be updated on this page. The effective date above will change when it is updated.
